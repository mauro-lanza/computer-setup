# Manager registry

> Generated by `scripts/managers generate` from each role's
> `meta/manager.yml`. Do not edit by hand.

Managers are the engine's building blocks. Plugins supply *data*;
managers know *how* to apply it. Tiers:

- **generic** — data-driven workhorses (packages, files, settings, repos, shell).
- **specific** — bespoke idempotency for a named tool via its own CLI.
- **engine** — self-management machinery (orchestration, drift, upgrade).

## Generic managers

| Manager | Capabilities | Summary |
|---|---|---|
| `git` | — | Render ~/.gitconfig and ~/.gitignore_global from layer vars. |
| `homebrew` | — | Install Homebrew formulae and casks (baseline + selected; adopt allow-list). |
| `layer_configs` | — | Deploy capability config files/templates to their destinations. |
| `macos` | — | Apply macOS system defaults + Rectangle defaults; deploy macos-capture. |
| `repositories` | — | Clone catalogued repositories if missing, run post_clone hooks once (opt-in). |
| `shell` | — | Deploy the engine CLI snippet, layer shell snippets (capability-gated via the '# cs:requires-capability:' directive), and the layer-provided ~/.zshrc and ~/.p10k.zsh. |

## Specific managers

| Manager | Capabilities | Summary |
|---|---|---|
| `runtimes` | nvm, tfenv | Set the default Node version (via nvm) and Terraform version (via tfenv). Specific because each is driven through the tool's own CLI. |
| `vscode` | vscode | Install VS Code extensions and deploy user settings. Specific because it executes the `code` binary (idempotent extension installs). |

## Engine managers

| Manager | Capabilities | Summary |
|---|---|---|
| `computer_setup` | — | Orchestration core — platform check, layer var/capability merge, capability registry, adoption probe, and the derived role interface (packages, config deploys, reminders). Also the deploy_layer_file primitive. |
| `drift_correction` | — | Install the daily drift-check LaunchAgent, wrapper, and layer-sync helper. |
| `upgrade` | — | Upgrade managed tools to latest — brew, Galaxy collections, Node (opt-in). |
